STAR 一句话公式：
在【背景/规模】下，为达成【目标】，我【关键动作 2-3 个，含技术或方法】，最终【量化结果 + 影响面】。

动词替换表：
负责 → 主导 / 牵头 / 独立完成
参与 → 承担 X 模块 / 负责 Y 环节
优化 → 重构 / 提效 / 降本 / 缩短链路
提升 → 从 A 到 B（+X%）
搭建 → 从 0 到 1 建设 / 沉淀 SOP

量化素材清单（写简历前先问自己）：
规模：用户数、订单量、QPS、数据量、预算金额、团队人数
效率：耗时、周期、人天、自动化率、发布频率
质量：错误率、投诉率、NPS、留存率、复购率
商业：GMV、ROI、CAC、LTV、毛利、成本降幅
基线：改造前是多少？行业均值为多少？

自查清单：每条 bullet 是否有数字？是否只有一个动作？是否第一行就能看到结果？
